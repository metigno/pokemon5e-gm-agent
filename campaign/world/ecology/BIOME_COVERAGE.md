# ASTERIA BIOME COVERAGE

Asteria deliberately contains a logical home for every biome class used by the current Pokémon 5e species catalog.

| Biome class | Asteria examples |
|---|---|
| Abyss | Fossa Aster |
| Badland | Calanchi di Solaria, Caldera Ceneriva, Cava Grigia |
| Beach | Costa di Sale, Arcipelago Luminara |
| Cave | Gallerie Ferrox, Cava Grigia, Caldera Ceneriva |
| City | Valedarsena, Ferravia, Mareasale, Meridiana |
| Desert | Calanchi di Solaria |
| Field | Via delle Ginestre, Fattoria del Vento |
| Forest | Bosco Bruma, Lago Specchio, Luminara |
| Glacier | Ghiacciaio Boreale |
| Grassland | Fattoria del Vento, Sentiero delle Colline |
| Industrial | Ferravia, Valedarsena, Meridiana |
| Jungle | Arcipelago Luminara |
| Lake | Lago Specchio |
| Mountain | Monti Ferrox, Altacima |
| Ocean | Mareasale, Costa di Sale, Luminara |
| Polar sea | Mare di Brina |
| Pond | Palude Mirto, Lago Specchio |
| Reef | Arcipelago Luminara, Costa di Sale |
| River | Canale delle Ruote, Rivafonda |
| Riverside | Canale, Palude Mirto, Lago Specchio |
| Ruin | Rovine del Primo Faro |
| Swamp | Palude Mirto |
| Tundra | Monti Ferrox, Ghiacciaio Boreale |
| Volcano | Caldera Ceneriva |
| Woodland | Bosco Bruma, Borgo Salice |

This does not mean every species with a compatible biome is common there. The species registry applies local rarity and family rules.
