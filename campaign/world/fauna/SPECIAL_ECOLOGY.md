# SPECIAL ECOLOGY CLASSES

## normal_wild
Stable or localized living population. Can enter ordinary encounter selection.

## fossil
Living specimens exist only in regulated paleobiological populations unless a later world event changes that.

## form_state
Not an independent random population. Resolve through the base species/form rules.

## legendary
Event-only presence. Never random.

## mythical
Event-only presence. Never random.

## ultra_beast
Incursion/anomaly only. Never native random fauna.

## paradox_past / paradox_future
Temporal anomaly only. Never ordinary fauna.

## unique_variant_event
A specific rare/unique variant requiring its own story condition.

These classes override rarity tables.
