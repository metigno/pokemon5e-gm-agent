# Audio offline

Installare localmente il pacchetto tramite `python3 bookgame/scripts/import-audio-package.py /percorso/P5E_AudioPack_M01-M12.zip`. Non versionare musiche o versi Pokémon nel repository: sono materiali di terzi e la gratuità del gioco non concede diritti di redistribuzione.

Senza il pacchetto il client funziona comunque con una sintesi locale originale semplificata. L'audio è disattivato finché l'utente non lo abilita.
